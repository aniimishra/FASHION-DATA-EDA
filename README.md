# Fashion Data Analysis

This project is about analyzing customer reviews from a fashion e-commerce dataset. I used Python to understand what customers think about different products and what factors are related to their ratings and recommendations.

The project includes analysis of customer ratings, age groups, departments, recommendations, and customer sentiment. I also used text analysis to understand whether customer reviews were positive, negative, or neutral.

The data was explored and visualized using different charts and graphs to make the patterns easier to understand.

### What I worked on:

* Customer rating analysis
* Customer age analysis
* Age vs. rating comparison
* Department-wise recommendations
* Customer sentiment analysis
* Sentiment comparison across departments
* Data visualization using charts

### Tools Used:

Python, Pandas, NumPy, Matplotlib, Seaborn, NLTK, and TextBlob(Took help from AI tools for this).

The main goal of this project was to practice **data cleaning, exploratory data analysis (EDA), visualization, and basic sentiment analysis** while finding useful patterns in real-world customer review data.
